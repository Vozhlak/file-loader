# File-loader

CLI-приложение на Go для параллельной загрузки больших файлов по HTTP с поддержкой докачки, retry и graceful shutdown. Прогресс каждой загрузки сохраняется в JSON-файл рядом с целевым файлом, поэтому после прерывания загрузку можно продолжить с уже скачанных чанков.

## Возможности

- Параллельная загрузка файла по чанкам.
- Докачка после перезапуска через `.progress` файл состояния.
- Повторные попытки загрузки для временных сетевых ошибок.
- Graceful shutdown по `Ctrl+C` с сохранением состояния загрузки.
- Отдельные progress bar для нескольких URL.

## Требования

- Go 1.25+
- Доступ к серверу, который поддерживает `Accept-Ranges: bytes`

## Сборка

```bash
go build -o downloader .
```

## Использование

```bash
./downloader ./downloads https://example.com/file.zip
```

Можно передать несколько URL:

```bash
./downloader ./downloads https://example.com/file1.zip https://example.com/file2.zip
```

## Как это работает

1. Приложение делает `HEAD`-запрос и получает имя файла, размер и поддержку range-запросов.
2. Файл разбивается на чанки по 10 MB.
3. Перед началом загрузки создаётся файл состояния `имя_файла.progress`.
4. Каждый успешно записанный чанк помечается в `downloaded_chunks` и состояние атомарно сохраняется.
5. При повторном запуске приложение читает `.progress` и продолжает загрузку только отсутствующих чанков.

## Пример

```bash
go run main.go ./downloads https://example.com/data.zip
```

Пример файла состояния:

```json
{
  "url": "https://example.com/data.zip",
  "total_size": 52428800,
  "chunk_size": 10485760,
  "total_chunks": 5,
  "downloaded_chunks": [true, true, false, false, false]
}
```

## Graceful shutdown

- Первый `Ctrl+C` отменяет `context.Context`, останавливает выдачу новых задач воркерам и сохраняет актуальный прогресс в `.progress`.
- Второй `Ctrl+C` завершает процесс принудительно.
